# Architecture Decision Records (ADRs)

ADRs capture durable engineering decisions. Implementation details live in code and in `docs/api/dashboard-openapi.yaml` for HTTP.

| ID | Title | Status | File |
|----|-------|--------|------|
| 001 | Rust-first single-host trading engine | Accepted | [001-rust-first-polymarket-engine.md](001-rust-first-polymarket-engine.md) |

When adding a new ADR, use the next number, keep **Status** explicit (Proposed / Accepted / Superseded), and link any superseded ADR from the new file.
