# get firm position limits

Retrieves position limits from a specific firm.

#### Path Parameters

The UUID of the firm to get position limits for

Example:

`"f81d4fae-7dec-11d0-a765-00a0c91e6bf6"`

#### Response

Successfully retrieved firm position limits

Example:

`"f81d4fae-7dec-11d0-a765-00a0c91e6bf6"`
