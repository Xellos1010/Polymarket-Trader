# get block trader

Retrieves information for a block trader with the specified UUID.

#### Path Parameters

The block-trader's UUID

Example:

`"e80d6a4e-af9f-4fcb-a819-3d22c7017279"`

#### Response

Successfully retrieved block trader

Example:

`"123e4567-e89b-12d3-a456-426614174000"`
