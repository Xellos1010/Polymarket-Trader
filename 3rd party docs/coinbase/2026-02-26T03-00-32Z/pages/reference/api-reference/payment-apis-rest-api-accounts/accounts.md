# accounts

Accounts

The Accounts APIs enable developers to create and manage accounts for themselves (Entity) or for their Customers. An Account is a container that holds assets and can be used for transacting. Accounts can be of different types including entity accounts, customer accounts, prime accounts, and business accounts. These APIs are implemented by the cdp-accounts service.
