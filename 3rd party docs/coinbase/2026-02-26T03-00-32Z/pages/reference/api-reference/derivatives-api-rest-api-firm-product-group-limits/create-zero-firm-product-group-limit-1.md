# create zero firm product group limit 1

Create Zero Firm Product Group Limit

Firm Product Group Limits

Creates a zero position limit to a specific firm/product group that disables trading for that combination.

#### Body

Product group limit parameters

Example:

`"f81d4fae-7dec-11d0-a765-00a0c91e6bf6"`

Available options

:

`CURRENCY`,

`EQUITY`,

`ENERGY`,

`METALS`,

`INTEREST_RATE`,

`AGRICULTURE`,

`CRYPTO`

#### Response

Successfully created firm product group limit
