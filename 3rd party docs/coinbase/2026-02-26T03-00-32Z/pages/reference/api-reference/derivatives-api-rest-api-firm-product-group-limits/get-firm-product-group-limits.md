# get firm product group limits

Get Firm Product Group Limits

Firm Product Group Limits

Retrieves product group limits for a specific firm, including individual product limits within each group

#### Path Parameters

The UUID of the firm to get product group limits for

Example:

`"f81d4fae-7dec-11d0-a765-00a0c91e6bf6"`

#### Response

Successfully retrieved firm product group limits

Example:

`"f81d4fae-7dec-11d0-a765-00a0c91e6bf6"`

Available options

:

`CURRENCY`,

`EQUITY`,

`ENERGY`,

`METALS`,

`INTEREST_RATE`,

`AGRICULTURE`,

`CRYPTO`
