# get block trade entity

Retrieves information for a block trade entity with the specified UUID.

#### Path Parameters

The block-trade-entity's UUID

Example:

`"e80d6a4e-af9f-4fcb-a819-3d22c7017279"`

#### Response

Successfully retrieved block trade entity

Example:

`"123e4567-e89b-12d3-a456-426614174000"`

Example:

`"Block Trade Entity 1"`
