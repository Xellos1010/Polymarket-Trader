# get block trade account

Retrieves information for a block trade account with the specified UUID.

#### Path Parameters

The block-trade-account's UUID

Example:

`"e80d6a4e-af9f-4fcb-a819-3d22c7017279"`

#### Response

Successfully retrieved block trade account

Example:

`"123e4567-e89b-12d3-a456-426614174000"`

Example:

`"Client Account 1"`

Example:

`"abcdef12-3456-7890-abcd-ef1234567890"`

Available options

:

`CTI1`,

`CTI2`,

`CTI3`,

`CTI4`

Available options

:

`HOUSE`,

`CLIENT`,

`MARKET_MAKER`
