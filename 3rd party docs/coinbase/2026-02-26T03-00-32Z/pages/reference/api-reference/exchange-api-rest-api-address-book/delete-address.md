# delete address

```
curl --request DELETE \
  --url https://api.exchange.coinbase.com/address-book/{id} \
  --header 'cb-access-key: <api-key>' \
  --header 'cb-access-passphrase: <api-key>' \
  --header 'cb-access-sign: <api-key>' \
  --header 'cb-access-timestamp: <api-key>'
```
