# downloads

Coinbase Derivatives Exchange (CDE) provides downloads for FIX, SBE, and REST:

-   [cde-fix44-xml-dictionaries-latest.zip](https://developer.chrome.com/derivatives/downloads/cde-fix44-xml-dictionaries-latest.zip)
-   [cde-sbe-xml-schemas-latest.zip](https://developer.chrome.com/derivatives/downloads/cde-sbe-xml-schemas-latest.zip)
-   [cde-public-api-spec.json](https://developer.chrome.com/derivatives/downloads/cde-public-api-spec.json)

### FIX Dictionaries

The FIX zip file includes the following files:

```
cde-fix44-xml-dictionaries % tree
.
├── cde-fix44-dropcopy-api.xml
├── cde-fix44-market-api.xml
└── cde-fix44-orders-api.xml

```

### SBE Schemas

The SBE zip file includes the following files:

```
cde-sbe-xml-schemas % tree
.
├── cde-sbe-market-api.xml
├── cde-sbe-orders-api.xml
└── cde-sbe-session-api.xml

```
