# overview

Coinbase Prime offers robust APIs for institutional trading, custody, and staking. These APIs are purpose-built to support integration of Crypto-as-a-Service (CaaS), payments, and trading infrastructure into your applications. Concepts pages provide foundational guidance on core functionality and integration workflows to accelerate your development process.

## Core Concepts

### Account Structure

-   **[Account Structure](https://developer.chrome.com/prime/concepts/account-structure)** - Multi-entity, multi-portfolio organizational structure and API scoping

### Trading

-   **[Trading Overview](https://developer.chrome.com/prime/concepts/trading/trading)** - Product pairs, order creation, tracking, fills, and cancellation workflows
-   **[Order Types](https://developer.chrome.com/prime/concepts/trading/order-types)** - Supported order algorithms and execution strategies
-   **[Market Data](https://developer.chrome.com/prime/concepts/trading/market-data)** - Methods for order book and candles maintenance
-   **[Trading Fees](https://developer.chrome.com/prime/concepts/trading/trading-fees)** - Fee structures, calculation methods, and API response field explanations
-   **[Trade Financing](https://developer.chrome.com/prime/concepts/trading/trade-financing)** - Trade financing, buying power
-   **[FIX](https://developer.chrome.com/prime/concepts/trading/fix)** - Financial Information eXchange protocol for institutional trading
-   **[RFQ](https://developer.chrome.com/prime/concepts/trading/rfq)** - For placing and accepting a Request for Quote (RFQ) order type
