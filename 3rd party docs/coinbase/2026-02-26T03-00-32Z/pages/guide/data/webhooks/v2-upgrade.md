# v2 upgrade

## Overview

This guide outlines the steps to upgrade from Webhooks v1 to v2. Webhooks v1 will be deprecated on January 26th, 2026. Upgrade is designed to be seamless and instant. The primary change developers must make is modifying their codebases to accept the new v2 payload structure and updating their signature verification method.
