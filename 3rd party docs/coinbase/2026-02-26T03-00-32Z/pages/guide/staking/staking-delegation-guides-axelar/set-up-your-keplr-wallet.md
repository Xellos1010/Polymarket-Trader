# set up your keplr wallet

1.  In Chrome, add the [Keplr wallet extension](https://chrome.google.com/webstore/detail/keplr/dmkamcknogkgcdfhhbddcghachkejeap) by following the on-screen prompts.
2.  Open the browser extension and select **Create new account**.
3.  Copy your mnemonic seed phrase and store it somewhere safe where it cannot be lost or compromised.

4.  Establish an account name and password, then select **Next**.
5.  Confirm your mnemonic seed phrase and select **Register**.
