Staking with Avalanche Wallet

Avalanche Wallet is a non-custodial wallet for storing Avalanche-based assets. It is available as a web-based wallet at [https://wallet.avax.network/](https://wallet.avax.network/). If you do not have any AVAX stored on Avalanche Wallet, start at [1: Set Up and fund Wallet with AVAX](https://developer.chrome.com/staking/staking-delegation-guides/avalanche/avalanche-wallet/setup-and-fund-avalanche-wallet) If you already have AVAX stored on your Avalanche Wallet, proceed to [2: Stake AVAX to Coinbase with Avalanche Wallet](https://developer.chrome.com/staking/staking-delegation-guides/avalanche/avalanche-wallet/stake-avax-to-coinbase)
