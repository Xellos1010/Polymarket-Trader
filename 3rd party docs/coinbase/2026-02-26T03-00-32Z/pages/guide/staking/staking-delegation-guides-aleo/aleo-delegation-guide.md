# aleo delegation guide

[Aleo](https://aleo.org/) is a L1 smart contract blockchain focused on enabling and building private decentralized applications using zero-knowledge. It’s built on SnarkOS and SnarkVM allowing for single proof of execution validations and a private environment that processes transactions at scale making verifiable proofs the only onchain requirement. Staking to the Coinbase validator contributes to the protocol consensus and as a result, stakers earn a proportionate amount of inflationary rewards provided to the validator they stake with.

Protocol Parameter

Value

Minimum to stake
