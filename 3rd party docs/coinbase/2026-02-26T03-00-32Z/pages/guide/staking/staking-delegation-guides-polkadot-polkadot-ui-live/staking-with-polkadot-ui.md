# staking with polkadot ui

The `Polkadot{.js}` extension is a web-based wallet for account key management, designed to be used alongside wallet UIs including the [Polkadot.js Chrome web-based wallet extension](https://chrome.google.com/webstore/detail/polkadot%7Bjs%7D-extension/mopnmbcafieddcagagdcbnhejhlodfdd?hl=en). You may delegate your DOT from the Polkadot UI by importing your DOT stash using a controller, or importing via the Polkadot app on a Ledger S or X hardware device. If you do not have any DOT stored on your Polkadot UI wallet, start at [1: Import Stash and fund Polkadot UI with DOT](https://developer.chrome.com/staking/staking-delegation-guides/polkadot/polkadot-ui-live/import-stash-and-fund-polkadot-ui). If you have already imported your Polkadot Stash to the Polkadot UI, proceed to [“2: Stake DOT to Coinbase with Polkadot UI](https://developer.chrome.com/staking/staking-delegation-guides/polkadot/polkadot-ui-live/stake-with-polkadot-ui).
