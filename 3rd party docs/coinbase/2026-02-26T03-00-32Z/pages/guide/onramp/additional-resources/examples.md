# examples

Experience everything Onramp has to offer by [downloading and running a sample app](https://developer.chrome.com/get-started/demo-apps/starter/onramp-demo-app):

## Sample web app

1.  Clone the [demo web repo](https://github.com/coinbase/onramp-demo-application).
2.  [Make a secret API key](https://developer.chrome.com/onramp/introduction/getting-started#step-4%3A-create-a-secret-api-key) and move it into the repo as `api_keys/cdp_api_key.json`.
3.  Follow the instructions in the README to run the app.

## Sample mobile app

1.  Clone the [demo mobile repo](https://github.com/coinbase/onramp-v2-mobile-demo).
2.  Follow the instructions in the README to run the app.
