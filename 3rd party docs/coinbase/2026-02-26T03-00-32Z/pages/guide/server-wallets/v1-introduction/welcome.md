# welcome

Server Wallet enables developers to create secure wallets and automate onchain actions with minimal code, focusing on product innovation rather than complex wallet infrastructure management.

**DEPRECATION NOTICE:** Server Wallet v1 (formerly known as Wallet API and MPC Wallet) is being deprecated as of Feb 2, 2026. We have sent warning emails to all active v1 users over the past several months. [Migrate to Server Wallet v2](https://developer.chrome.com/server-wallets/v2/introduction/welcome) ASAP.
