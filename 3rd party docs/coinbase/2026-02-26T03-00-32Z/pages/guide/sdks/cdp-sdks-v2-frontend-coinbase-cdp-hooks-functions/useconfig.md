```
function useConfig(): {

```

Hook to get the CDP being used by the SDK.

## 

[​](#returns)

Returns

```
{
  config: Config;
}

```

### 

[​](#config)

config

```
config: Config;

```

## 

[​](#example)

Example

```
function App() {
  const { config } = useConfig();
  return (
    <div>
      <p>Project ID: {config.projectId}</p>
    </div>
  );
}

```
